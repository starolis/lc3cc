# lc3cc

A C compiler targeting the LC-3, the teaching ISA of Patt and Patel's
"Introduction to Computing Systems: From Bits and Gates to C/C++ and Beyond"
(3rd edition). Compiles a documented subset of C to LC-3 assembly using the
textbook's calling conventions.

Status: pre-release. The initial public release (v1.0.0) is in preparation;
the full README, documentation, and source land with it.
